A few minutes to your first page

Compose on Windows.

The portable preview runs on 64-bit Windows 10 and 11. It doesn’t need an installer, an account or administrator access.

Download Windows ZIP ↓

Open the app

  1. Download Compose-Windows.zip.
  2. Right-click the downloaded file and choose Extract All.
  3. Open the extracted Compose folder.
  4. Double-click compose.exe.

This is an unsigned preview, so Windows may show an unrecognized-app notice. Download only from this site or the linked project repository. Graphics and interactive behavior still need wider testing on physical Windows PCs.

Verify your download

Open PowerShell in the folder containing the ZIP and run:

Get-FileHash .\Compose-Windows.zip -Algorithm SHA256

Compare it with the published SHA-256 checksum.

Make your first document

Choose a blank page or an editable preset, give it a name, then select Create document. Double-click text to edit it. Drag objects to move them. The inspector controls fonts, colors, dimensions and image appearance.

Use Ctrl+S to save, Ctrl+Shift+S for Save As, Ctrl+O to open and Ctrl+Z to undo. Ctrl+Shift+Z or Ctrl+Y redoes a change.

Keep an editable copy

Your .compose file keeps every page, layer and embedded image. Use Export for PNG or an editable DOCX in Word-compatible mode. Canvas layouts stay in .compose format. Save regularly; desktop crash recovery is not implemented yet.

Preview limitations

DOCX import, native Windows printing and automatic text flow between pages are not available. Screen-reader support and physical Windows hardware behavior need further validation. The optional background-removal feature uploads the selected image to a shared service.

Found a problem? Report an issue with your Windows version and the steps that caused it.
