A few useful details

Before you
make a start.

Is Compose free?

Yes. Compose is free and open source under the MIT license. You can use the app without an account or subscription.

Does my work stay on my computer?

Your documents save locally as .compose files, with their images embedded. Editing works offline. Online image search needs a connection; optional background removal sends the selected image to a shared processing service. Save regularly: desktop crash recovery is not available yet.

Can I use it with Microsoft Word?

Choose Word-compatible mode to export editable DOCX with text and images. Compose canvas mode keeps its freeform layouts in .compose files. Opening existing DOCX files and automatic text flow between pages are not supported yet.

Is this a finished release?

Compose is in active development. This is an early Windows preview, with automated engine checks and portable packaging. Native printing is currently macOS-only. Graphics compatibility, accessibility and physical Windows hardware need further testing.

What about other platforms?

The repository includes native macOS and Android apps. The ready-to-download package on this page is for Windows. See the project instructions to build another platform.
